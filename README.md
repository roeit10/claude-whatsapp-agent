# סוכן וואטסאפ אישי עם Claude Code

סקילים ל-Claude Code שמקימים לכם **סוכן וואטסאפ אישי שרץ על המחשב שלכם**.
אתם כותבים הודעה רגילה בוואטסאפ — והוא בודק לכם את היומן, מוצא קבלות במייל, ועושה דברים.

בלי שרת. בלי ענן. הכל אצלכם.

```
מספר וואטסאפ ייעודי → Green API → poller על המחשב → Claude Code → תשובה בוואטסאפ
```

---

## התקנה

מהתיקייה של הפרויקט שלכם:

```bash
git clone https://github.com/roeit10/claude-whatsapp-agent.git /tmp/claude-whatsapp-agent
mkdir -p .claude/skills
cp -R /tmp/claude-whatsapp-agent/skills/* .claude/skills/
cp -R /tmp/claude-whatsapp-agent/templates .claude/skills/whatsapp-agent-setup/
```

ואז פותחים Claude Code ואומרים לו:

> תתקין לי סוכן וואטסאפ

זהו. הוא לוקח מכאן.

## הנעילה — הדבר הכי חשוב כאן

הסוכן עונה **רק לבעלים שלו**. הודעות מקבוצות, מזרים ומכל אחד אחר נרשמות ביומן ונזרקות.

זה לא הגדרה שאפשר בטעות לכבות — זה שלוש שכבות בקוד:

1. הגדרות ה-instance מוקשחות בהתקנה
2. פעולה רק על הודעה נכנסת שה-`chatId` שלה זהה בדיוק לזה של הבעלים
   (קבוצות נגמרות ב-`@g.us` ולכן נופלות מעצמן)
3. שליחה מותרת רק ליעדים ברשימה מאושרת

בהתקנה הסוכן **קולט את מזהה הבעלים מהודעה אמיתית** — הוא לא מרכיב אותו ממספר טלפון.
זה מכוון: וואטסאפ מחזירה לפעמים מזהה בפורמט אחר, וניחוש היה נכשל בשקט.

**כל הודעה שנכנסת נרשמת** ב-`logs/messages-YYYY-MM-DD.jsonl` — כולל אלה שנזרקו.

## מה צריך

- **Node.js 18+** — [nodejs.org](https://nodejs.org)
- **Claude Code**
- **מספר טלפון ייעודי** — לא המספר האישי שלכם. הסוכן יושב על המספר.

## דברים שכדאי לדעת מראש

**התוכנית החינמית של Green API מוגבלת ל-3 צ'אטים בחודש.** אחד מהם הולך על השיחה
שלכם עם הסוכן. זה מספיק כדי להתנסות ולהבין אם זה שווה לכם.

**Green API הוא לא הערוץ הרשמי של Meta.** זה פתרון שמתחבר לוואטסאפ שלכם.
השתמשו בו על מספר ייעודי, ואל תשלחו דרכו הודעות המוניות.

**Composio לא תומך ב-Windows** ב-CLI שלו. יש מסלול חלופי דרך `@composio/mcp`
שמתועד בסקיל, אבל הוא **טרם נבדק על Windows אמיתי**.

**הסוכן מוגדר לקרוא, לא לשלוח.** אם תבקשו ממנו לשלוח משהו למישהו — הוא יראה לכם
קודם מה הוא עומד לשלוח ויחכה לאישור.

**מספר חדש לא מצטרף לבד לקבוצה קיימת.** מנהל הקבוצה צריך להוסיף אותו.
