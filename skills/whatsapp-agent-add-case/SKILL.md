# הוספת יכולת לסוכן

מוסיף לסוכן קיים ב-`~/whatsapp-agent/` יכולת חדשה.
דורש סוכן שכבר עובד — אם לא, קודם `whatsapp-agent-setup`.

## איך יכולת נוספת עובדת

הכל **לפי דרישה** — המשתמש כותב בוואטסאפ והסוכן מגיב.
אין מה לחווט ואין תזמון: `CLAUDE.md` של תיקיית הסוכן הוא מה שמכוון אותו.
הוסף שם סעיף קצר וברור, וזהו.

> אין הרצה מתוזמנת ב-v1. אל תוסיף cron או Task Scheduler מאחורי הגב של המשתמש —
> סוכן ששולח הודעות מיוזמתו בלי שהוא מבין למה, נכבה תוך יומיים.

---

## הקייסים

### 1. קבלות וחשבוניות מהמייל
לפי דרישה. הוסף ל-`CLAUDE.md`:
```
כשמבקשים קבלות/חשבוניות: חפש ב-Gmail דרך composio בטווח שביקשו,
החזר רשימה — ספק, תאריך, סכום. אל תשלח כלום לאף אחד בלי אישור מפורש.
```

### 2. קביעה ביומן מהוואטסאפ
לפי דרישה:
```
כשכותבים לך משהו שנשמע כמו פגישה ("נפגשים מחר ב-3 עם דני"),
הצע אירוע יומן: תאריך, שעה, משך, כותרת. צור אותו רק אחרי "כן".
```

### 3. סריקת קבוצות (לפי בקשה)
**דורש שמספר הסוכן יהיה חבר בקבוצות.**
מספר חדש לא מצטרף לבד — מנהל הקבוצה צריך להוסיף אותו. אמור זאת מראש.
ובחינם יש תקרה של 3 צ'אטים בסך הכל, כלומר שתי קבוצות לכל היותר.

### 4. תזכורת ללקוח על פגישה מחר
**הקייס היחיד שבו הסוכן שולח למישהו אחר.** דורש `EXTRA_SEND_TARGETS` ב-`.env`.

בנה אותו כך: הסוכן מכין את הנוסח ושולח אותו **לבעלים** לאישור.
רק אחרי "שלח" הוא שולח ללקוח.

> הסיבה לא תיאורטית: חברת מועדון סיפרה שסוכן שלה שלח תזכורת
> **למספר אקראי** למרות שהמספר נראה נכון בהגדרות. אישור אנושי לפני שליחה
> הוא לא בירוקרטיה.

### 5. "מה פספסתי"
"מה פספסתי היום?" — סיכום מהיומן והמייל. הכי בטוח, קריאה בלבד.

## תהליך ההוספה

1. **הבן מה המשתמש רוצה בפועל.** "שיטפל לי במיילים" זה לא הגדרה.
   שאל שאלה אחת ממוקדת.
2. **בדוק שהחיבורים קיימים** — `composio connections list`. חסר → המשתמש מחבר ב-https://dashboard.composio.dev
3. **כתוב** את הסעיף ל-`CLAUDE.md`.
4. **בדוק באמת:**
   ```bash
   cd ~/whatsapp-agent && echo "<הבקשה כפי שהמשתמש ינסח אותה>" | claude -p --output-format json \
     --model sonnet --effort medium --allowedTools Bash Read Grep \
     --strict-mcp-config --mcp-config mcp.json
   ```
   `num_turns` = 1 → לא השתמש בכלים. **זו תקלה**, גם אם התשובה נשמעת נכון.
5. **הפעל מחדש את ה-poller** אם נגעת ב-`.env`.

## אל תעשה

- אל תיתן שליחה לזרים בלי אישור אנושי בכל פעם
- אל תניח שהסוכן חבר בקבוצה — בדוק
- אל תנפח את `CLAUDE.md`. הוא נטען בכל הרצה; ארוך = איטי ויקר
